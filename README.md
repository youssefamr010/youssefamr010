## 🚀 Featured Projects

### 🛡️ SudoSoc — Hybrid AI-Powered IDS/IPS

<div align="center">

<img src="./assets/sudosoc_architecture.png" width="100%" alt="SudoSoc Architecture — 3-Layer Detection with IPS Auto-Block" />

</div>

<br/>

> 🎯 **95%+ detection accuracy** across attack classes — including encrypted traffic analysis without decryption.

**Key capabilities:**
- **3-layer detection:** Rule-based signatures → Ensemble ML (Random Forest + XGBoost) → LLM contextual analysis
- **Automated IPS:** Confirmed threats trigger `iptables` rule injection — blocks attacker IPs within seconds
- **Encrypted traffic analysis:** Entropy + timing + behavioral signatures flag suspicious TLS/SSL flows without decryption
- **Self-healing:** Concept Drift Monitor detects baseline shifts and triggers selective model retraining

<br/>

### ☁️ Hybrid Cloud Secure Connectivity Lab

> On-prem ↔ AWS via **IPsec/IKEv2 VPN** · 4 VLANs with inter-VLAN routing · ACL-enforced segmentation · RFC 1918 addressing across 3 sites (60+ endpoints) · End-to-end payload encryption verified via packet capture.
