### 🛡️ SudoSoc — Hybrid AI-Powered IDS/IPS

| Layer | Technology | Purpose |
|-------|-----------|---------|
| **1 — Rules** | Signature Engine | Known-attack pattern matching |
| **2 — ML** | Random Forest + XGBoost (Stacking) | Anomaly detection across DDoS, port scans, brute-force, encrypted-channel threats |
| **3 — LLM** | HuggingFace + Groq APIs | Contextual analysis & explainable alerts |
| **IPS** | `iptables` Auto-Injection | Blocks attacker IPs in seconds — zero manual intervention |
| **Drift** | Concept Drift Monitor | Detects baseline shifts & triggers selective retraining |

> 🎯 **95%+ detection accuracy** across attack classes — including encrypted traffic analysis without decryption.

### ☁️ Hybrid Cloud Secure Connectivity Lab

> On-prem ↔ AWS via **IPsec/IKEv2 VPN** · 4 VLANs with inter-VLAN routing · ACL-enforced segmentation · RFC 1918 addressing across 3 sites (60+ endpoints) · End-to-end payload encryption verified via packet capture.
