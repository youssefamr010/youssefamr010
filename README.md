## Projects

### SudoSoc — Hybrid AI-Powered IDS/IPS

A 3-layer intrusion detection and prevention engine reaching **95%+ detection accuracy** across DDoS, port scanning, brute-force, and encrypted-channel anomalies.

| Layer | Technology | Purpose |
|:---|:---|:---|
| Rules | Signature Engine | Known-attack pattern matching |
| ML | Random Forest + XGBoost (Stacking) | Behavioral anomaly detection |
| LLM | HuggingFace + Groq APIs | Contextual analysis and explainable alerts |
| IPS | iptables Auto-Injection | Blocks attacker IPs within seconds |
| Drift | Concept Drift Monitor | Detects baseline shifts and triggers retraining |

Key capabilities include encrypted-traffic detection without decryption (entropy analysis, packet timing, connection-behavior signatures), an automated IPS response pipeline with zero manual review, and an online-learning feedback loop for continuous model improvement.

### Hybrid Cloud Secure Connectivity Lab

Simulated on-premises environment connected to AWS via site-to-site IPsec/IKEv2 VPN. Segmented into 4 VLANs with inter-VLAN routing, ACL-enforced cross-segment restriction, and RFC 1918 addressing across 3 sites supporting 60+ endpoints. End-to-end payload encryption verified via packet capture.
